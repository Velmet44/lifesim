# Display & ethics rules (from validation review §10 + gpui color rules)
# Enforced in both earth-gpui and earth-cli export (shared LUT).

- All civ outputs labeled SCENARIO, bands-first (P10-P90), never point pop/GDP.
- No sub-global targeting: aggregates global + ≤4 latitude bands. No per-region ranking UI.
- Collapse/famine/migration scenarios: explicit opt-in + context banner; no alarming language automation.
- Twin history uses prescribed forcings; free-emissions runs tagged COUNTERFACTUAL.
- Every export chart embeds provenance + uncertainty; deep-future (>10kyr) watermarked SPECULATIVE.
- Color: no rainbow; fixed vmin/vmax per layer+era; shared earth-core::colormap; colorblind-safe default on.
- No coupling to real infrastructure control; scenario editor is not policy prescription.
